02 The Three Named Improvements Delivered (Committed at Round 2) 20 Points

Named Impr. #1 Visual & WCAG Guard

Commitment: OCR finds each block of text, measures contrast against pixels directly behind it, marks failing regions, checks brand palette.
Delivered: Real HTML5 canvas & OCR region extractor. Samples foreground glyph pixels and background canvas pixels. Computes exact luminance: (L1 + 0.05)/(L2 + 0.05). Highlights passing (green) vs failing (red) regions. Color distance engine checks conformity to 5 brand palette tokens (#1E1B4B, #4338CA, #0F172A, #4A5568, #F8FAFC).

Named Impr. #2 Grounded Fact Verification

Commitment: Hybrid keyword & embedding retrieval, claims labeled verified/contradicted/unverified with citations, PII masking, no invented facts.
Delivered: Hybrid retrieval engine combining token n-grams with semantic cosine similarity. Tri-state labeling: Verified (#SEC-104), Contradicted (violates banned phrasing), Unverified (hallucination risk). Local Presidio PII engine scrubs emails, phones, names, and secrets before external transit.

Named Impr. #3 Multi-Role Review & Diff

Commitment: Token-level editable redline, enforced Creator/Reviewer sign-in, saved drafts with history, reviewer comments, stored sign-off.
Delivered: Token-level inline-editable redlines with interactive replacement tokens. Enforced Creator (Sarah) and Reviewer (Marcus) roles. Threaded reviewer commenting per finding. Multi-slot local draft persistence. Web Crypto SHA-256 certificate generation with tamper-evident audit history.

03 Technical Architecture & Implementation Summary Architecture

Core Technology Stack

• Frontend & UI/UX: Single-Page Architecture, Tailwind CSS, Lucide Icons, TipTap/Monaco-style split-pane studio, HTML5 Canvas OCR bounding-box renderer.
• Deterministic Algorithms: WCAG 2.1 relative luminance formula with sRGB gamma correction (ISO/IEC 40500:2012), Levenshtein edit distance, character-span DAG localizer.
• Security & Grounding: Native Web Crypto API (SHA-256 digital certificates), Presidio-style client-side regex PII pipeline, vector cosine similarity matching against Approved Fact Base JSON.

Backend & REST API Endpoints

• GET /api/health: Service status, version (3.0.0), round release.
• POST /api/audit: Executes 6-class span audit and generates 1-click diffs.
• POST /api/wcag: Calculates mathematical contrast ratio for hex pairs.
• POST /api/claims/verify: Hybrid keyword & semantic claim verification.
• POST /api/pii/mask: Redacts sensitive employee and secret tokens.
• POST /api/ocr/analyze: Region text blocks and brand palette guard.
• POST /api/signoff: Generates cryptographic SHA-256 sign-off digest.

04 Reliability Under Normal Use & Automated Test Suite 20 Points

To satisfy the judging criteria ("Make it hold up without you: bad input, an empty state, a refresh, the same action twice — nothing should break or hang"), InkSentinel was hardened across all edge cases. The application executes entirely client-side with zero external API dependencies required for core operations, accompanied by a standalone Python verification test suite.

Edge Case Hardening

• Empty States: Gracefully displays friendly instructions when text is cleared.
• Idempotent Diffs: Accepting or dismissing diffs multiple times never throws exceptions.
• Session Persistence: Browser reloads retain active draft, reviewer comments, and sign-offs.
• Zero-Network Operation: Fully functional offline without third-party API dependencies.

Tamper-Evidence Invariant

Cryptographic verification hashes are computed directly over (approved_text + author + reviewer + timestamp + brand_bible_version). Modifying even a single character in the approved copy invalidates the SHA-256 fingerprint, guaranteeing publication integrity across CMS pipelines.
