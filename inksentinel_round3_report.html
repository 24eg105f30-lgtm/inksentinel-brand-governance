01 Product Overview & Complete Feature List 25 Points

InkSentinel AI is an assistive brand governance co-pilot designed to resolve the tension between rapid content production and regulatory exposure. Unlike blunt black-box LLM wrappers, InkSentinel performs deterministic, explainable audits against Brand Bible clauses (§1.3, §2.1, §3.4, §4.2, §4.5, §5.1) and Approved Fact Bases (#SEC-104, #PRC-201, #FEAT-305, #PERF-402). Suggestions are strictly advisory; no copy is published or silently altered without creator approval.

Complete Feature List (Round 3 Hardened Release)

1. Text & Claim Studio: Split-pane workspace with real-time Brand Health Score (0–100) across 5 core violation categories.
2. Explainable Redline Diff: Character-span diffs citing clause IDs and grounded fact records with 1-click adoption.
3. Token-Level Redline Canvas: Inline word-level diff visualizer with editable replacement tokens before adoption.
4. Hybrid Claim Grounding Sandbox: Tri-state claim verification (VERIFIED, CONTRADICTED, UNVERIFIED) enforcing the zero-invented-facts invariant.
5. Client-Side Regex PII Masking: Pre-inference redaction of emails, phones, names, and API keys before external transit.
6. Visual & WCAG Guard: Canvas luminance calculator evaluating text against background pixels with interactive region selection.
7. Brand Palette Conformity Guard: Hex distance validator checking colors against 5 approved enterprise brand tokens.
8. AI Tone Review (Gemini Flash): Advisory tone review via Vercel serverless function with deterministic edge fallback.
9. Role Enforcement & Comments: Creator vs Reviewer role toggles with inline threaded comments saved to localStorage.
10. Cryptographic Audit Sign-Off: Web Crypto SHA-256 certificate generation with exportable JSON audit trail receipt.
11. Guideline Ambiguity Heatmap: Infraction analytics with simulated telemetry and AI-assisted policy rewrite suggestions.
12. Fact Base Ingestion Modal: Runtime GUI dialog allowing compliance teams to ingest new verified fact records.
13. Local Python REST Server & Test Suite: Mirror server (server.py) and unit test suite (test_suite.py) with zero pip dependencies.

03 Technical Architecture & Truthful Implementation Summary Architecture

Technology Stack & Network Boundaries

• Browser Client: Single-Page Architecture using semantic HTML5, Tailwind CSS, Lucide Icons, and HTML5 Canvas. Core deterministic rule audits, WCAG luminance math, regex PII masking, and Web Crypto SHA-256 hashing run 100% locally on-device. CDN assets (Tailwind, icons) require initial internet connectivity.
• Edge Serverless AI (Vercel): api/tone.js calls Google Gemini (gemini-1.5-flash) via an OpenAI-compatible endpoint. Features dual-layer fallback heuristics: if the key is missing or rate-limited, local brand heuristics score the copy with zero crashes.
• Grounding & Retrieval: Implemented as hybrid keyword plus character n-gram cosine vector similarity against JSON facts—a lightweight, dependency-free stand-in for heavy vector DBs.

Local Python REST Server & Algorithms

• Standard Library Backend (server.py): Uses standard Python 3.9+ (zero pip packages). Serves static files and REST endpoints: /api/health, /api/guidelines, /api/facts, /api/ambiguity, /api/wcag, and /api/audit.
• WCAG Luminance Formula: Deterministic sRGB gamma correction (ISO/IEC 40500:2012): L = 0.2126R' + 0.7152G' + 0.0722B'.
• Cryptographic Audit Payload: Generates tamper-evident SHA-256 digest hashing: ${text}|${author}|${reviewer}|${timestamp}|BrandBible-2.4.0.

06 Known Limitations & Commercial Roadmap 15 Points

Declared Scope Boundaries & Limitations

• Role Enforcement: UI-level demo toggles with localStorage; no production OAuth/SSO.
• OCR Scope: Uses preset bounding coordinates for the built-in ad banner. Custom image upload demonstrates the workflow and falls back to preset demo bounding regions; arbitrary in-browser OCR is on the roadmap.
• Ambiguity Heatmap: Uses simulated historical baseline telemetry (1,420 simulated audits) + live telemetry.
• Persistence: LocalStorage is per-device/browser and clears on cache wipe.

Commercial Development Roadmap (Post-Hackathon)

• Q1 2027: Native Figma plugin and Adobe Creative Cloud extension for visual WCAG inspection on canvas; integration of in-browser WebAssembly OCR (Tesseract.js).
• Q2 2027: CI/CD GitHub Action and Headless CMS (Contentful/Sanity) webhooks blocking non-compliant copy before deployment.
• Q3 2027: Enterprise SSO (Okta/SAML 2.0), multi-tenant Fact Base isolation, and SOC-2 audit logs.
• Q4 2027: Localization support for global Brand Bibles with localized regulatory rules.
